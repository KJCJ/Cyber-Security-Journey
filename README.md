## Current setup

- **Home lab:** Raspberry Pi 4 running Ubuntu, with Kali Linux tools in Docker
  for practising against deliberately vulnerable targets on an isolated network.
- **Local AI assistant:** Ollama running Dolphin-Mistral locally for offline
  analysis of code and security concepts. No data leaves my machine.
- **Learning platforms:** TryHackMe (in progress), PortSwigger Web Security Academy
