## Format

Each write-up follows the same structure:

- **Context** — what I was working on
- **What I found** — the vulnerability in plain terms
- **Why it's a vulnerability** — OWASP category and impact
- **How I fixed it** — the code or configuration change
- **Verification** — evidence the fix works
- **What I learned** — the takeaway

## Ethics

Everything here was tested on systems I own or on platforms designed for
legal, ethical training. No third-party systems were involved.
